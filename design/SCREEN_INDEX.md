# Horizon 页面索引

8 套风格共用以下 73 个场景。交互图集：[index.html](index.html)；导出图册：[exports/index.html](exports/index.html)。

| 编号 | 分组 | 场景 | 关键设计 |
| --- | --- | --- | --- |
| A01 | 开始与项目 | [首次打开](index.html?screen=welcome) | 无需登录，先打开本地项目；AI 与插件不进入首次启动必填流程。 |
| A02 | 开始与项目 | [工作区与项目总览](index.html?screen=projects) | 工作区分组、项目搜索、固定项目、最近访问与后台休眠状态。 |
| A03 | 开始与项目 | [创建工作区](index.html?screen=workspace-create) | 工作区是项目集合，创建不会搬动磁盘文件。 |
| A04 | 开始与项目 | [添加本地项目](index.html?screen=project-add) | 选择目录、显示名与所属工作区；已有项目去重后直接打开。 |
| A05 | 开始与项目 | [克隆仓库](index.html?screen=clone) | 仓库地址、目标目录、克隆进度、取消与完成后的打开操作。 |
| A06 | 开始与项目 | [项目操作菜单](index.html?screen=project-menu) | 固定、重命名显示名、在新窗口打开、休眠、从工作区移除；移除不删除磁盘文件。 |
| B01 | 阅读与编辑 | [默认工作台](index.html?screen=home) | 项目导航、文件树与代码区常驻；AI 和终端关闭；标签属于当前项目。 |
| B02 | 阅读与编辑 | [文件操作](index.html?screen=file-menu) | 新建文件或目录、重命名、复制路径、系统中显示与移到废纸篓。 |
| B03 | 阅读与编辑 | [快速打开与命令](index.html?screen=quick-open) | 统一入口搜索文件，使用 > 进入命令；键盘导航并显示快捷键。 |
| B04 | 阅读与编辑 | [项目内搜索](index.html?screen=search) | 按文件分组结果，显示匹配上下文；范围与大小写选项保留在搜索区域。 |
| B05 | 阅读与编辑 | [搜索无结果](index.html?screen=search-empty) | 保留查询，提供取消限制与修改搜索范围；不清空用户输入。 |
| B06 | 阅读与编辑 | [轻量编辑与未保存](index.html?screen=edit) | 未保存使用标签圆点；Git 修改使用 M。磁盘变化和未保存状态分别表达。 |
| B07 | 阅读与编辑 | [分栏预览](index.html?screen=preview) | Markdown 源码与预览并列；预览是可选插件，可单独关闭。 |
| B08 | 阅读与编辑 | [关闭未保存文件](index.html?screen=unsaved) | 保存、放弃本次编辑、取消；取消返回原上下文。 |
| B09 | 阅读与编辑 | [大文件阅读](index.html?screen=large-file) | 显示文件大小与当前加载范围，允许继续加载或用系统应用打开。 |
| B10 | 阅读与编辑 | [文件结构与符号](index.html?screen=outline) | 结构导航复用侧栏；基础标题结构可用，语义符号由语言插件提供。 |
| C01 | Git 工作流 | [更改与行内差异](index.html?screen=git-changes) | 未暂存与已暂存分组；点击不同组展示对应差异。 |
| C02 | Git 工作流 | [暂存与提交](index.html?screen=git-commit) | 提交范围明确显示已暂存文件；提交信息为空或没有暂存时禁用提交。 |
| C03 | Git 工作流 | [提交历史](index.html?screen=git-history) | 紧凑历史列表与提交详情；按提交查看文件差异。 |
| C04 | Git 工作流 | [分支与远端同步](index.html?screen=git-branch) | 当前分支、搜索、新建分支、上游状态、拉取与推送。 |
| C05 | Git 工作流 | [合并冲突处理](index.html?screen=git-conflict) | 当前版本、传入版本与结果区域；逐处解决后标记完成。 |
| C06 | Git 工作流 | [放弃更改确认](index.html?screen=git-discard) | 明确受影响文件与操作后果，危险动作不设为默认聚焦按钮。 |
| C07 | Git 工作流 | [同步失败与重试](index.html?screen=git-error) | 保留当前更改，展示失败原因与可执行下一步；凭据从系统流程获取。 |
| C08 | Git 工作流 | [并排差异](index.html?screen=git-split) | 前后版本并排；窄窗口自动使用行内差异，避免压缩代码到无法阅读。 |
| D01 | AI 工作流 | [AI 尚未连接](index.html?screen=ai-empty) | 说明可接入能力，连接入口进入设置；不阻断文件或 Git 使用。 |
| D02 | AI 工作流 | [按项目对话](index.html?screen=ai-chat) | 当前项目、所选上下文、模型与发送状态可见；聊天默认不执行写入。 |
| D03 | AI 工作流 | [上下文选择](index.html?screen=ai-context) | 显式选择文件、选区或 Git 差异，展示将发送的范围和移除入口。 |
| D04 | AI 工作流 | [任务执行中](index.html?screen=ai-running) | 任务模式单独启用；显示当前步骤、修改文件与停止操作。 |
| D05 | AI 工作流 | [待授权操作](index.html?screen=ai-permission) | 命令、工作目录与本次影响明确列出；允许一次或拒绝，不默认永久放行。 |
| D06 | AI 工作流 | [审查 AI 修改](index.html?screen=ai-review) | 文件列表与 diff 联动，可按文件接受或撤回；不自动提交 Git。 |
| D07 | AI 工作流 | [连接失败与重试](index.html?screen=ai-error) | 保留草稿与上下文；可重试、切换连接或打开连接设置。 |
| E01 | 终端 | [按需终端](index.html?screen=terminal) | 底部终端绑定项目目录；关闭面板和结束进程是不同操作。 |
| E02 | 插件中心 | [插件中心 · 发现扩展](index.html?screen=plugins) | 固定入口；分类发现能力，区分已安装、已启用与按需运行。 |
| E03 | 插件中心 | [插件详情与贡献点](index.html?screen=plugin-detail) | 完整详情页展示来源、版本、权限、激活条件和界面贡献点。 |
| E04 | 插件中心 | [扩展失败与诊断](index.html?screen=plugin-error) | 显示具体失败与日志，可重试或在当前项目停用。 |
| E05 | 插件中心 | [已安装与作用域](index.html?screen=plugin-installed) | 查看已安装扩展，按作用域筛选；启用、停用与配置就近操作。 |
| E06 | 插件中心 | [本地扩展包安装](index.html?screen=plugin-install) | 选择扩展包，查看来源、兼容性和安装后启用范围。 |
| E07 | 插件中心 | [安装进度与取消](index.html?screen=plugin-installing) | 检查、授权、安装与注册入口分步展示；取消不启用半成品。 |
