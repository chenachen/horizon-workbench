# Horizon 视觉设计规范

版本 0.4 · 2026-10-31。配合 [交互图集](index.html)、[页面清单](SCREEN_INDEX.md)、[交互规范](../docs/ux/INTERACTION_SPEC.md) 使用。

## 1. 产品界面的中心

代码是默认主区域。首屏只保留工作区与项目导航、文件树、文件标签、代码和状态栏。Git 复用文件侧栏；AI 从右侧打开，终端从底部打开；插件中心在顶栏保留固定入口；外观、布局、AI 接入、扩展与快捷键配置进入设置。

视觉借用 Material 的表面层级、强调容器、状态和形状系统。使用系统字体、细线图标和克制的动效。品牌名为 Horizon / 地平线，原型品牌符号使用 Lucide `orbit`；这是可替换的项目标识，没有使用游戏素材。

| 暖纸 | 项目列表置于文件树上方 | 260 px | 8 px | 34 px | 暖白、低分隔、一体阅读；项目总览采用列表 |

八套使用共同场景与操作语义。表内尺寸是早期各组合的视觉参考；0.4 首选尺寸统一由 F10 和 CUSTOMIZATION_DESIGN 定义，可调整。深空、极光默认深色；其他方向默认跟随系统。所有方向均提供浅色和深色颜色对。设置中的主题选择会改变当前预览。

使用顺序：选择布局插件 → 主题 → 尺寸/密度 → 明暗 → 配色与背景。雾蓝是均衡基线，暖纸侧重长时间阅读，石墨侧重紧凑操作，鸢尾侧重柔和的 Material Expressive 观感；其他布局同样交付并保持自己的导航方式。

## 3. 颜色与令牌

源文件：[atlas.css](source/atlas.css)、[base.css](source/base.css)。所有产品令牌使用 `--h-` 前缀并限定在当前工作台。

| 令牌 | 用途 |
| --- | --- |
| `--h-bg` | 窗口与导航底色 |
| `--h-surface` | 代码、内容和弹窗表面 |
| `--h-low` | 次级区域、卡片与柔和分区 |
| `--h-high` | 输入背景、分段器底色、状态容器 |
| `--h-ink` / `--h-muted` | 正文与辅助文字 |
| `--h-line` | 低强调分隔与边框 |
| `--h-accent` / `--h-on-accent` | 高强调动作及其文字 |
| `--h-tonal` / `--h-on-tonal` | 当前项目、当前文件等选中容器 |
| `--h-green` / `--h-green-bg` | 增加、成功状态 |
| `--h-red` / `--h-red-bg` | 删除、失败和危险操作 |
| `--h-radius` / `--h-row` | 当前风格形状与密度 |
| `--h-tree` / `--rail-width` | 文件侧栏与项目栏宽度 |
| `--h-font` | 代码字体大小 |

正文目标对比度 4.5:1，控件边界与图标目标 3:1；最终原生实现需结合真实字体、显示缩放和禁用状态复核。选中状态同时使用形状和文字，Git 使用 `+`、`−`、`M` 等符号，错误使用说明与图标，不能仅依靠色相传达含义。

## 4. 字体与节奏

- UI：系统无衬线字体，macOS 使用系统字体与苹方，Windows 使用 Segoe UI 与中文系统字体。
- 代码：SFMono-Regular / Consolas / Liberation Mono / monospace，默认 13 px；窄窗口为 12 px。代码区保持独立字号。
- 页面标题 23–26 px，弹窗标题约 20 px，正文 12–14 px，辅助信息 11 px。品牌文字 16 px。
- 主要字重 400 / 500。标题依靠尺寸和空间形成层级，不大量使用粗体。
- 基础间距 4 / 8 / 12 / 16 / 24 / 32 px。阅读内容行高宽松；文件列表保持可扫描的行距。
- Lucide 图标通常 16 px，品牌符号 23 px。图标按钮提供可访问名称和工具提示。

## 5. 窗口与区域

原尺寸设计稿以 1280 × 800 px 工作台为主。它是对照用设计画板，不是桌面应用的固定尺寸。原型支持更窄的会话预览。

| 区域 | 规则 |
| --- | --- |
| 顶栏 | 品牌、工作区、快速打开、视图、AI、设置；随风格约 49–70 px |
| 项目导航 | 每个项目独立保存文件标签和布局；选中项目始终可辨认 |
| 文件侧栏 | 默认 195–260 px；真实应用拖动范围建议 180–320 px |
| 文件标签 | 未保存用圆点；Git 修改用文件列表 `M`，两者不混用 |
| 代码区 | 剩余空间优先分配；基础阅读不要求启用语言服务 |
| AI 面板 | 318 px 参考宽；空间不足时改用覆盖层 |
| 终端 | 底部按需出现；收起面板和结束进程是两个动作 |
| 状态栏 | 分支、更改数、语言和编码；不展示未经测量的性能数字 |
| 设置弹窗 | 分类导航 + 设置内容；即时生效；窄窗口分类改为横向列表 |

macOS 采用左上窗口控制示意；Windows 采用右上最小化、最大化、关闭示意，快捷键使用 Ctrl。原生标题栏拖拽、双击、缩放、窗口阴影由真实桌面实现完成。

## 6. 响应式与面板优先级

宽窗口允许项目、文件、代码与 AI 并列。常规宽度的 AI 采用覆盖式面板，避免代码区继续变窄。小于 640 px 时文件侧栏隐藏为可关闭浮层，顶部操作分成两行；项目管理、搜索与设置仍可进入。

收缩顺序：隐藏次要状态文字 → 缩短项目标签 → AI 变为覆盖层 → 文件侧栏变为浮层。关闭浮层后返回代码阅读。原型已检查 1024、736、360、320 px 四个页面宽度；桌面产品的最小窗口尺寸需在双端原生壳上确认。

设计场景 G06 将工作台限制到 760 px 来展示窄布局。H04 给出区域关系图。规范页面和表单允许纵向滚动；代码和差异区域可以保留局部水平滚动。

## 7. 组件与状态

| 组件 | 主要状态与行为 |
| --- | --- |
| 按钮 | filled 主动作、tonal 次动作、描边、文字、禁用、危险；同组保持明确主次 |
| 文件行 | 默认、悬停、选中、Git 修改、冲突；目录展开状态属于项目会话 |
| 输入 | 标签、当前值、帮助或错误；错误说明放在对应字段旁 |
| 标签页 | 当前、非当前、未保存、不可读取；关闭未保存时进入保存确认 |
| 切换器 | 状态可见，标题说明实际控制对象；设置区分全局和项目覆盖 |
| 菜单 | 项目、文件、视图三个上下文；危险动作使用明确名称 |
| 弹窗 | 有标题、关闭与返回；危险动作不默认聚焦；Esc 退出非进行中的对话 |
| 通知 | 保存、复制、暂存等轻量反馈不打断阅读；可恢复失败保留输入 |
| 加载 | 局部骨架保留布局；不做无意义循环闪烁 |
| 空态 | 明确原因和一个主要下一步，不用大插画占据阅读空间 |

键盘操作采用原生按钮、输入、选择器；保留焦点环。模态打开时底层不可交互，Tab 限制在弹窗内。触控适配目标约 44 px；桌面高密度按钮依赖键盘与指针操作。

## 8. 核心流程的视觉约束

**Git。** 未暂存与已暂存分组；工作目录相对暂存区的差异，与暂存区相对 HEAD 的差异分别标识。提交信息与提交范围靠近提交按钮。冲突显示当前、传入和结果。推送失败保留本地结果，提供具体恢复动作。

**AI。** 项目、模式、模型和上下文可见。聊天与任务分开；任务有停止操作；权限显示命令与目录；修改进入审查页面。原型仅展示这些流程，按钮不会调用模型、运行命令或修改磁盘。

**扩展。** 插件系统是核心架构，插件中心为一级功能。安装、启用、运行、休眠、失败分别表达；能力、权限、贡献点、更新与卸载形成完整管理流程。详见 [插件中心设计规范](PLUGIN_CENTER.md)。具体插件按需使用，基础文件与 Git 保持可用。

**设置。** 外观、布局、编辑器、项目资源、AI、Git、快捷键、数据共用一套弹窗。项目覆盖有恢复继承入口。连接配置是独立子表单，输入的密钥不由原型保存。

## 9. 交付与开发衔接

- `source/screens.json` 是稳定页面目录；A–H 分别代表八个功能分组。
- `source/styles.json` 保存风格名称和结构；`atlas.css` 保存各风格实际令牌与布局。
- `source/app.js` 为本地演示逻辑；不作为文件系统、Git 或 AI 的真实业务实现。
- `horizon-atlas.fragment.html` 供会话内预览，`index.html` 为可离线打开的交互图集。
- `exports/png/<style>/<编号>-<场景>.png` 为逐页原尺寸图；每套 PDF 含封面与 73 页设计。
- `exports/manifest.json` 提供文件路径、画面尺寸、页面编号和说明，便于导入设计管理工具。

原型可以实际切换页面、风格、主题、密度和项目，模拟 Git 暂存与提交、AI 对话和设置；系统目录选择、真实文件读写、网络连接、进程、扩展运行及持久化属于后续桌面实现。设计规范中的完整产品行为由产品、交互与技术文档继续约束。

## 布局插件与外观设置（0.4）

八套预设均为布局插件与主题的默认组合，结构/配色可独立选择；默认雾蓝。F01 外观总览、F02 布局插件新增关联 F10 区域尺寸、F11 背景、F12 配色、F13 组合、F14 恢复。交互与默认范围见 [CUSTOMIZATION_DESIGN](../docs/ux/CUSTOMIZATION_DESIGN.md)。

原型的设置会存入浏览器本地存储；图片缩至长边1280用于预览。桌面实现将使用 Rust 资产目录与2560上限，需另测解码/纹理资源。原型用预装样式模拟布局包选择，不代表真实插件安装或 CodeMirror 状态迁移已经完成。
