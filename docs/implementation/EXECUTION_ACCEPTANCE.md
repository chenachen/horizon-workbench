## 2. 产品价值与实现架构

- 核心价值是一切插件化、轻量、低占用，同时重视 UI、日常体验和插件可玩性。用户接受几百 MB 以平衡体验与低占用，不能为追求数字牺牲设计与已确认功能。
- 技术基线是 Tauri 2 + Rust + React/TypeScript + CodeMirror 6 + Cordis core。以现有 Cordis/React 实验为起点完成原生验证；DeepSeek Harness 参考服务、插槽、主题和生命周期，必要时继续研究 Harness/VS Code 的实际实现。历史 SolidJS/Electron 探索不能覆盖当前选择。
- 最小宿主提供窗口、工作区/项目登记、扩展生命周期、权限、进程与资源管理、设置和草稿恢复基础。文件树、编辑器、搜索、Git、终端、快速启动、Pi、布局/主题通过明确插件接口贡献能力。
- 插件安装不等于运行，隐藏面板不等于停止，暂停/禁用/卸载必须真正回收实例、事件、监听、任务与自有进程。默认不用 AI、终端、语言服务时不启动对应运行时；后台项目可休眠；有界文档/搜索/日志/聊天缓存，未保存文档不得被淘汰。

## 3. 工作区、文件与日常使用

- 工作区容纳多个单根项目。实现添加/去重、克隆、改名/排序/固定/移除、路径失效恢复；移除登记不删除源码。项目切换恢复各自标签、选区、滚动、树展开、搜索、Git 草稿和 AI 会话，不能把上下文串到其他项目。
- 文件树按需加载；快速打开/命令面板、项目文本搜索、高亮阅读、轻量编辑、撤销重做、查找替换、复制粘贴、保存及预览闭环可用。支持中文输入、UTF-8/BOM、LF/CRLF 和末行换行保持；非支持编码和二进制如实降级。
- 新建/重命名不覆盖冲突路径，删除走废纸篓，脏文件关闭有保存/放弃编辑/取消。保存检查磁盘版本，外部变更保留双方；保存失败不丢内容，崩溃草稿可恢复。Markdown 预览与基础结构按插件提供。
- 大文件、超长行、深目录和海量路径不能把 UI 阻塞。部分加载/只读/截断范围可见，部分文件不可保存覆盖完整文件。正常文件仍必须具有完整编辑与搜索体验。
