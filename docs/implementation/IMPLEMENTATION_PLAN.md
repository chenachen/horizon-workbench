## 1. 实施基线与责任边界

**优先级：用户 2026-10-30 补充与 2026-10-31 确认（已落实于产品 PRD 0.4.0）高于旧研究、旧页面备注与本计划早期草稿。Everything is a Plugin 是产品主线；默认附带文件树、代码和 Git 不等于固化在不可拆核心。不自研 Agent。2026-10-31 用户在产品会话确认：Pi 为首版默认候选，Codex/Claude 先留接口；本计划采用该最新范围。**

本计划把产品需求落成可交给编码会话执行的任务。TASK 表示尚待实现的工作，不表示已有实现。设计原型中的文件、Git、AI 和终端演示不计作功能或性能证据。

当前候选路线为 Tauri 2 + Rust + React / TypeScript + CodeMirror 6。工作区包含多个项目；一个项目对应一个本地根目录，Git、搜索、文档和 Agent 会话都带项目身份。最小宿主只保留窗口/布局槽位、项目记录、扩展注册与权限、进程/任务管理、持久化和草稿恢复基础设施。文件树、编辑器、搜索、Git、Agent、终端和启动器作为扩展按需激活。先完成一个默认附带扩展的真实安装与卸载链路，再完成文件链路和两个项目切换。旧研究“首版只有一个项目”的范围不覆盖用户现在的多项目要求。

页面 ID 是交互状态索引，并非独立路由。初读为 56 页，2026-10-31 复核增至 73 页；新增扩展中心状态同样按需求分层，不代表全部高级能力进入 MVP。H01–H05 是规范；G 系列多数是同一组件的状态。默认工作台保留项目导航、文件树和代码，AI 与终端按需展开，配置进入设置弹窗。

本计划中的源码位置是编码时的建议落点，不声明目录已存在。接口字段、错误码和模块归属以接口文档为准；编码会话不得另建一套同义协议。开始任务前先确认对应文档版本，完成时记录实现修订、实际测试命令、平台、结果和遗留问题。除非用户另行授权，不提交、不推送。

批次表示依赖顺序，不等同于迭代周数。产品 M0 是技术验证，落在 S0/S1 及 TASK-008 的 Pi/进程早期探测；S2 对应 v0.1 核心里程碑，S3 补齐完整 MVP，S4 为发布验收。先验证候选技术的风险，避免在原生输入、文件正确性或基线资源问题未解决时铺满视觉页面。估算采用每项任务的实现和验证结果滚动更新；研究中的 6–10 周只是旧范围的建议区间，不作为本计划承诺。

### 2.1 UI 开工的最小契约

八套布局都作为插件交付，以下工作可以立即实施：项目/文件模型、IPC、文件读写、文档版本、保存冲突、扩展管理器、Git 能力代理、请求取消、持久化及资源生命周期。UI 基础层只需以下稳定契约：

1. 固定区域职责：项目导航、主侧栏、编辑区、可选辅助面板、状态反馈、全局设置弹窗；不固定八种候选中的某一种导航形状。
2. 所有尺寸、颜色、字体、圆角和密度经过语义令牌；组件不得把候选方案的颜色和几何值写入业务状态。
3. 一个可替换布局实现先覆盖 B01、B06、B08、G02、G06；面板开关和尺寸独立序列化，项目切换不得重置未保存文档。
4. 键盘焦点、禁用/处理中/错误状态、未保存提示和窄窗口优先级按交互规范执行。操作身份与快捷键不依赖图标形状。
5. 默认经典侧栏布局与雾蓝主题，八套布局分别验收；结构切换与外观设置按 CUSTOMIZATION_DESIGN 实施，无待选择的视觉阻塞。

## 3. 通用执行与完成定义

每个任务的输入包含对应 TASK、TRACEABILITY 中的 REQ/页面，以及相关架构和交互契约。涉及多个模块的任务先实现核心服务和契约，再接 UI；前端模拟结果不得被记录为真实文件、Git 或网络验收。

所有任务共同完成定义：目标行为可复现；成功、失败、取消和空状态中与任务有关的分支有处理；测试证据可定位；没有凭据进入日志；异步结果不会写入错误项目；不会遗留任务自己创建的监听、进程或订阅。未通过的项目保留明确状态，不以“后续优化”覆盖数据丢失、状态串用或不可取消的问题。

测试分层：纯模型和状态转换用单元测试；文件和 Git 用真实临时目录/仓库的集成测试；组件交互用浏览器测试；平台行为用真实安装的桌面包。只补能够验证任务风险的测试，不为静态文本或简单令牌重复实现测试。

任务交接记录模板：

```text
TASK-ID / 输入规范版本 / 实现修订：
实现范围与实际文件：
验收步骤、命令和平台：
预期 / 实际 / 证据位置：
资源释放或恢复结果：
未通过项及其阻断范围：
```

## 4. S0：基础契约

### TASK-001 — 桌面骨架与可复现构建

- **目标 / 输入**：按技术设计建立 Tauri 2 + React/TypeScript 桌面骨架；读取 ADR 的候选技术与版本核验表。保留当前设计资产的用途和访问方式。
- **模块 / 建议文件**：桌面入口、前端入口、Tauri 配置、capabilities、依赖锁文件；采用技术设计建议的单应用 crate 模块边界，扩展独立包；不为每个模块提前拆 crate。
- **依赖 / 边界**：无任务依赖。先单窗口；不引入 AI、终端、扩展宿主或后台语言服务。空宿主不得包含无法卸载的文件树/编辑器/Git 产品功能。依赖写精确版本并生成锁文件，禁止将设计包已有依赖误当桌面运行基线。
- **验收步骤**：在 macOS 与 Windows 构建相同修订的开发包和 release 包；离开开发服务器后启动 release 包；显示窗口、版本和可关闭操作；重复启动/退出五次。
- **必要测试**：两端构建和启动冒烟；验证关闭后无本应用遗留进程；检查 release 包没有开发用远程调试和测试服务器。
- **完成定义**：双端最小程序真实运行，安装/运行环境与锁定版本有记录。只有一端可用时标为部分完成，并明确 S1 双端门禁未通过。

### TASK-002 — 共享 DTO、IPC 错误、取消与事件归属

- **目标 / 输入**：实现接口文档的请求、响应、事件、项目身份、版本与取消规则，使前后端共享一份可生成或校验的契约。
- **模块 / 建议文件**：`core/ipc`、`contracts`、前端 `services/bridge`；错误转换和请求注册表。
- **依赖 / 边界**：依赖 TASK-001。每个调用携带真实扩展/项目身份并经过宿主能力代理。仅暴露清单内命令；UI 不获任意 shell、任意文件路径或系统凭据读取入口。不在此任务实现每个服务。
- **验收步骤**：发送合法、未知字段/非法值、未知项目、取消后到达及旧版本响应；切换项目时让原请求晚完成；检查结果只更新所属项目；错误含用户可操作信息且不泄漏密钥。
- **必要测试**：序列化契约样例双向校验；取消幂等、迟到结果、错误映射和乱序事件测试。
- **完成定义**：后续任务能复用请求与订阅封装，不自行拼装 IPC；版本和取消语义有可运行测试。

### TASK-003 — 工作区、项目与配置持久化

- **目标 / 输入**：实现工作区包含多个项目的数据模型，项目去重、显示名、最近访问、设置继承与 schema 版本迁移。页面 A01–A04、A06、F02、F04。
- **模块 / 建议文件**：`core/workspace`、`core/settings`、`core/storage`、前端项目 store。
- **依赖 / 边界**：依赖 TASK-002。项目根目录经过核心层登记，前端只持有项目 ID；移除项目不删除磁盘目录；不做账号、同步、跨仓库批量操作。
- **验收步骤**：创建两个工作区、加入两个项目、同一路径重复加入、重命名显示名、移除后再次加入、退出重开；模拟配置写入中断和旧版 schema；确认项目文件未被移动或删除。
- **必要测试**：路径身份去重、全局/项目覆盖、原子持久化与迁移失败回退；读取损坏配置时给出恢复选择并保留原文件。
- **完成定义**：数据可恢复且字段权威归属清楚；未知未来 schema 不被旧版本静默覆盖；凭据不存入普通配置。

## 5. S1：最小桌面纵向切片

### TASK-004 — 文件根授权、目录懒加载与只读树

- **目标 / 输入**：从系统目录选择器登记项目根，按需读取目录并显示文件树；A04、B01、G01、G02。
- **模块 / 建议文件**：宿主文件权限代理、默认文件树扩展、`FileTree` 与项目目录缓存。
- **依赖 / 边界**：依赖 TASK-003、TASK-025。文件树作为默认附带扩展激活；路径规范化和根范围检查放 Rust；处理符号链接、大小写与 Windows 路径。此任务只读，不递归预载所有文件内容。
- **验收步骤**：打开含 Unicode、空格、重名大小写、无权限子目录和符号链接的样本；展开一万路径项目，滚动时列表只渲染可视项；切项目后原目录结果不得串入新树。
- **必要测试**：越界相对路径、链接越界、目录读取失败、分页/取消和项目释放；两端路径样本集。
- **完成定义**：根与文件身份可被后续文档/Git 接口共享，目录错误局部呈现，关闭项目后缓存和订阅按策略释放。

### TASK-005 — 文档打开与最小 CodeMirror 视图

- **目标 / 输入**：实现文档模型独立于组件生命周期；读取文件、按需高亮、标签切换、编码/换行信息和大文件入口；B01、B09、G02。
- **模块 / 建议文件**：默认代码扩展中的文档控制器、`DocumentStore`、`CodeSurface`、语言包加载器；宿主仅提供恢复存储和受控文件能力。
- **依赖 / 边界**：依赖 TASK-004。先支持接口契约规定的编码和文件大小；二进制/不支持编码不按普通文本保存；不默认启动 LSP。大文件阈值和截断信息必须真实。
- **验收步骤**：打开小文本、空文件、CRLF、UTF-8 BOM、二进制、大文件和长行样本；切换五个标签、再切项目，内容、选区和滚动位置正确；不存在文件显示 G02。
- **必要测试**：解码与换行保存元数据测试、并发打开去重、迟到加载、视图销毁与恢复；真实 WebView 中文输入先做冒烟。
- **完成定义**：默认代码扩展可独立启停；只读查看链路真实可用；UI 明确完整加载或受限阅读，不把截断文本误当完整文档。

### TASK-006 — 编辑、保存、外部修改与未保存保护

- **目标 / 输入**：实现版本化编辑、保存、关闭保护和外部修改冲突；B06、B08、G02；遵守接口中的文档版本与磁盘版本前置条件。
- **模块 / 建议文件**：默认代码扩展保存协调器、文件写入服务、`CodeSurface`、未保存/冲突弹窗。
- **依赖 / 边界**：依赖 TASK-005。显式保存先行；自动保存只在其设置任务通过后启用。禁止用磁盘变化覆盖脏 buffer；禁止“放弃本次编辑”顺带执行 Git 丢弃。
- **验收步骤**：修改后保存并校验磁盘字节；保存期间继续输入；外部程序同时改文件；只读目录/磁盘写入失败；在关闭标签、移除项目、切换工作区、退出窗口时分别选保存、放弃和取消。
- **必要测试**：乐观版本冲突、原子替换失败、换行/BOM、写入后版本推进、保存中新增编辑仍为 dirty；IME composition 期间快捷键和关闭行为双端人工验证。
- **完成定义**：未保存内容不静默丢失，冲突不得被普通重试覆盖；失败后 buffer 和编辑上下文仍在；状态中的未保存圆点与 Git 的 M 独立。

### TASK-007 — 监听、会话恢复与后台项目生命周期

- **目标 / 输入**：保存每项目标签/选区，布局使用全局设置；实现会话恢复与后台休眠；B01、F04、G01、G03；生命周期以技术设计为准。
- **模块 / 建议文件**：项目资源注册表、watcher 合并队列、恢复存储、前端项目 session。
- **依赖 / 边界**：依赖 TASK-006。休眠可停 watcher/派生计算，不能丢脏文档；隐藏面板、休眠项目和终止进程为不同动作。恢复数据限额执行技术设计，不无限复制历史。
- **验收步骤**：两个项目分别保留标签与未保存内容；切换、休眠、唤醒、外部批量修改、退出重开和模拟异常退出；路径失效时保持可恢复状态并提供重新定位。
- **必要测试**：watcher 风暴合并、自身写入去重、事件缺口后重扫、休眠时 dirty 保留、取消资源释放；恢复文件损坏与版本不兼容。
- **完成定义**：每个项目资源有归属、创建和释放点；恢复策略真实执行；异常退出恢复以可用快照为准，不宣称零数据丢失。

### TASK-008 — 纵向切片风险门禁

- **目标 / 输入**：用 TASK-001–007 的 release 应用验证候选路线可继续；执行本计划第 11 节固定数据与测量方法。
- **模块 / 建议文件**：桌面集成测试、测试 fixture、性能采集脚本与报告；建议 `tests/native`、`tests/fixtures`、`benchmarks`。
- **依赖 / 边界**：依赖 TASK-007、TASK-025。除文件链路外，必须以同一默认扩展执行安装→启动→暂停/恢复→禁用/卸载→重装，测量视图/任务/监听/进程变化。只测已实现文件工作流；Git/AI 未接入时不得记作完整浏览模式性能。模拟浏览器通过不等于原生通过。
- **验收步骤**：两端完成打开目录→打开文件→中文编辑→保存→外部冲突→切项目→重开恢复；20 次启动、60 秒稳定资源观察及 30 分钟标签/项目循环；记录进程明细。并做 Pi 固定版本/协议与只读 profile 探测，以及一组受控开发进程启动/停止试验，先暴露 PATH、协议和进程归属风险；完整适配与终端 UI 仍由 S3 任务完成。

## 11. 测试数据、指标与失败处置

### 11.1 固定样本

编码时建立可重建 fixture：一万源码路径、十万路径压力集、五个不超过 200 KB 的常用文档、十个变更文件约两千行 diff、单行超长/大文件/二进制/CRLF/BOM、权限拒绝/失效路径/符号链接、两个项目同名相对路径、带本地 bare remote 的两个 Git 工作副本。测试用文件全部放临时目录，不在用户项目上制造破坏样本。

记录 fixture 生成器版本和 seed、仓库提交与未提交 patch 哈希、设备 CPU/内存/系统版本/显示缩放、WebView/Git/应用与依赖版本、构建模式、采集工具和缓存条件。每次报告同时保留原始数据与计算口径。

### 11.2 建议性能目标，全部待实测

| 场景 | 初始建议目标 | 必须记录的口径 |
| --- | --- | --- |
| 空工作区 | 稳定内存 ≤ 200 MB | 启动稳定 60 秒；相关进程合计和逐项明细 |
| 日常浏览 | 稳定内存 ≤ 350 MB | 一万路径、五标签、Git 就绪；无终端/LSP/Agent |
| diff + 远程 API（旧研究参考，非本版主路径） | 旧目标稳定内存 ≤ 450 MB | 十文件/两千行 diff；保留旧口径来源，不用于替代真实 Agent 总资源目标 |
| 冷启动到可交互 | P95 ≤ 2 秒 | 至少 20 次；OS 缓存条件一致；起止时间定义固定 |
| 热文件打开到高亮 | P95 ≤ 150 ms | ≤ 200 KB；至少 20 次；首次打开另报 |
| 稳定空闲 CPU | 参考 ≤ 单核 1% | 无任务进行时连续 60 秒；后台工作另列 |
| 长时循环 | 30 分钟后资源可回落，无持续线性增长 | 标签/面板/项目循环；记录稳定区间与活动句柄数 |

外部 Agent、PTY 和开发启动方案新增场景必须重新测量：分别报告宿主+默认扩展、各外部进程增量与全流程总量。首轮以实测建立可用预算，不把旧“远程 API ≤450 MB”强套给本地 Agent 或开发服务器。Pi 专项另按 PI_AGENT_RESEARCH 的 PI-P01–PI-P08：首次 RPC 可用 P95≤1.5 秒、空闲增量建议≤120 MB、固定长会话总量建议≤600 MB、常规停止 P95≤1 秒、3 秒超时回收及 30 次循环。上述仍是建议门槛，须附相同版本/数据/平台的原始采样，不与基础宿主预算混成一个数字。

这些数值来自[现有研究](../../research/lightweight-workbench-research.html)，是建议验收目标，不是产品实测承诺。macOS 使用相关进程的 physical footprint；Windows 分别报告 private working set 与 private bytes，不能混成跨系统同义排行榜。WebView/GPU 共享资源的归属方法写入报告，不能只看主进程或 JS heap。启用终端、LSP、ACP 或本地模型时同时报告增量与总量。

### 11.3 风险验证的通过与失败路线

| 风险 | 通过证据 | 失败后的动作 | 阻断范围 |
| --- | --- | --- | --- |
| 系统 WebView / CodeMirror 中文输入 | 双端组合输入、选区、快捷键、保存字节正确 | 固定复现例，先修事件/组件集成；引擎层问题再评估替代编辑器 | 编辑功能和首版验收 |
| 保存与外部改动竞争 | 版本不匹配拒绝覆盖，脏 buffer 保留 | 修复文件/文档版本协议后重测，不上层绕过 | 所有写入、AI 补丁与扩展写操作 |
| 一万路径与 watcher 风暴 | 可取消、UI 可交互、任务释放 | 调整批处理、目录懒加载和结果限额；仍失败再换实现 | 搜索/批量刷新，不阻断基础模型 |
| WebView 整体资源预算 | 固定口径的 release 测量通过 | 先剖析常驻服务、缓存/视图；无法满足时重评 ADR | 轻量目标定案与发布 |
| Git/凭据/取消 | 真实仓库与两端原生认证成功；取消后状态可恢复 | 保留只读 Git / 本地提交已通过部分，明确阻断同步；不收集明文凭据绕过 | Git 对应能力 |
| 扩展 runtime 故障隔离 | 超时/崩溃不破坏核心；权限拒绝有效 | 暂停可执行扩展分发，保留已验证声明能力；记录产品范围影响 | 可执行扩展承诺 |
| Agent 直接写入的归属与恢复 | 任务基线可辨用户更改，取消与审查正确 | 不上线自动撤回；限定只读/建议模式或独立工作目录 | TASK-104，不阻断聊天 |
| 签名与发行环境 | 目标系统安装、签名校验、升级通过 | 内部测试继续；补齐签名与发行配置 | 正式分发 |

### 11.4 原生自动化能力核验

截至 2026-10-30，Tauri 2 官方文档区分 mock runtime 与真实 WebView：mock 测试不执行原生 WebView，因此只适合契约和服务级验证。[Tauri 测试文档](https://v2.tauri.app/develop/tests/)
