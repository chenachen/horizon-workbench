# 高度可定制 UI：布局、主题与外观设置

版本 0.4.1 · 2026-10-31。首版完整范围；对应 REQ-UI-006–011、TASK-034–037。产品形态为“可安装布局 × 可替换主题 × 用户外观偏好”，八套现有设计均落为预装布局插件。设置侧栏统一为“外观”，内容区采用主题与配色、布局与尺寸、背景图片、外观方案四个页签；配色和尺寸细项就地展开。

## 1. 用户操作与边界

| 操作 | 入口 | 改变什么 | 保存范围 |
| --- | --- | --- | --- |
| 换结构 | F02 布局插件；插件中心布局分类 | 项目导航位置、区域排列、分组与可用插槽 | 全局共用 |
| 换主题 | F01 外观总览 | 一组 light/dark 颜色、圆角与密度默认值 | 全局共用 |
| 调尺寸 | F10 区域尺寸；可调整分隔线 | 当前布局暴露的侧栏/导航/顶部/文件标签/面板尺寸 | 全局共用；拖动写全局 |
| 放背景图片 | F11 背景图片 | 本地静态图片、区域、显示方式、透明度与遮罩 | 全局共用 |
| 自配颜色 | F12 自定义配色 | 所选主题的 light/dark 语义令牌覆盖 | 全局共用 |
| 保存组合 | F13 外观组合 | 布局 ID、主题 ID、尺寸、背景与令牌引用 | 本地命名预设，选择后应用到全局 |

设置不能把左导航拖成底部导航；用户安装/切换布局插件完成结构变化。尺寸、背景、配色可自由组合。主题不携带命令、任意 CSS/JS 或网络资源。首版不提供任意拖拽 docking 编辑器。

八套默认布局分别提供独立项目栏、一体侧栏、顶部项目标签、紧凑工具栏、折叠导航、Expressive 分区、展开项目目录、底部项目栏。八套默认主题可跨布局选择。新安装仅启用经典侧栏布局及雾蓝主题；其他声明式资源不启动后台服务。用户可卸载默认包并从管理入口恢复。

## 2. 尺寸与适配

逻辑 px（CSS px），不是物理像素。下表是产品默认；布局可以在公共范围内缩窄约束并提供自己的初始值。F10 显示该布局实际支持的项、当前来源、数值输入、滑杆和单项重置。

| 字段 | 默认 / 允许范围 | 说明 |
| --- | --- | --- |
| sidebarWidth | 240 / 160–480 | 文件/Git 主侧栏 |
| navigationWidth | 64 / 48–280 | 展开导航布局默认 180；顶部/底部导航不显示此项 |
| topbarHeight | 56 / 40–88 | 不把原生交通灯/窗口控制缩小到不可操作 |
| tabHeight | 40 / 28–64 | 文件标签高度 |
| tabMinWidth | 120 / 80–240 | 文件标签最小宽；容器不够时滚动 |
| auxiliaryWidth | 320 / 240–560 | AI 等右侧辅助区域 |
| bottomHeight | 220 / 120–480 | 终端/输出面板 |
| statusHeight | 26 / 20–40 | 状态栏 |
| ui.fontSize / editor.fontSize | 13 / 11–20；14 / 8–40 | 全局字体偏好，与布局几何分开；命名外观方案不覆盖字体偏好 |

首选尺寸持久化；窗口缩小产生的有效尺寸只在内存中计算，不反写偏好。编辑区优先保留 320 px；不足时按布局声明折叠侧栏为浮层、辅助面板覆盖、文件标签滚动。无可用空间时进入单列窄窗规则。设置显示“首选 320 / 当前 240”。窗口恢复后回到首选值。拖动结束一次写盘，键盘方向键 1 px、Shift 10 px；取消拖动恢复旧值。

## 3. 继承、预览与恢复

有效值顺序：布局/主题默认 → 全局字段覆盖。切换项目不改变外观；旧版当前项目的外观在升级时迁移为全局，原配置保留备份。无隐含工作区层。几何以 `layoutId + field` 保存；颜色以 `themeId + mode + token` 保存；换包后保留旧包覆盖，换回恢复。主题与布局默认以各自声明为准，不互相重置。

即时预览采用内存草稿；有效编辑防抖持久化，失焦/关闭时 flush。无效数值或颜色保留编辑文本、显示错误，继续使用上个有效值。恢复默认删除对应全局覆盖。恢复当前布局尺寸仅作用于当前 layoutId；恢复当前主题配色仅作用于 themeId。删除命名组合不改变已应用配置。

F02 选中布局先校验已安装/启用、版本和必需 slot，再完成挂载与配置提交。期间可以取消；失败保留上个布局、草稿与任务，进入 F14 错误详情。正在中文组词时延后切换。换主题、调整尺寸、更新图片不触发文件重新打开、Git 刷新或 Agent 请求。

## 4. 图片背景

用户选择本地 PNG/JPEG/WebP；导入复制到应用资产目录，后续不依赖原图片路径。不接受 SVG、动画或远程 URL。建议导入上限 20 MiB、解码前检查最多 40 MP，超限说明原因；按方向处理后缩到长边 ≤2560，生成缩略图与显示资产。原图不额外长期保留。相同内容按 hash 复用，只有无配置/预设引用的资产才可清理。

F11 提供“整个工作台 / 侧栏 / 编辑区”、cover/contain、位置、图片可见度 0–40%（默认 12%）和遮罩 40–100%（默认 85%）。数字分别控制图片层和表面层；文字/图标保持不透明。对话框、权限与错误提示保留实色表面。关闭背景无需删除资产；删除资产前列出关联配置。缺失/损坏时退回主题底色，可重新选择。

同窗口只保留全局背景解码资源。2560×1440 RGBA 约 14 MiB 是像素数据估算，GPU/解码副本另测；建议纹理增量门禁 32 MiB，和全进程预算共同验收。不默认模糊、动态视频或多层大图。对比度检查文本/表面基础令牌；复杂图片仍需预览，不能以纯色比值宣称全图合格。

## 5. 自定义配色与外观组合

F12 按浅色/深色分别修改 accent、onAccent、surface、background、text、muted、border、selection，另有 success/warning/error 语义色。输入 HEX/RGB 经标准化；普通文本与基础表面比值低于 4.5:1 提示并提供恢复该项，允许用户预览选择。焦点、状态图标、错误文案仍提供非颜色线索。

F13 保存命名组合，列出引用的包与背景资产。导入 JSON 先校验 schema、令牌、范围和依赖；缺少布局/主题时列出包名，用户可安装或选择已安装替代；导入配置不执行代码、不自动启用包。纯 JSON 导出不含绝对路径与图片；显式选择“包含背景”时导出带内容摘要的资源包。范围、修订与冲突遵循设置协议。

## 6. 页面、组件与验收

| 页面 | 组件/关键状态 | 验收 |
| --- | --- | --- |
| F01 外观总览 | AppearanceSummary：布局、主题、尺寸、背景的独立入口 | 换主题保留布局与尺寸 |
| F02 布局插件 | LayoutPicker：预装八包、当前包、恢复入口 | 八包各可选；切换保留文档与任务 |
| F10 区域尺寸 | GeometryEditor：支持项、有效值、继承来源 | 数值/滑杆一致、重启恢复、窄窗不覆盖首选值 |
| F11 背景图片 | BackgroundEditor：空/处理中/就绪/失败/缺失 | 本地导入、预览、透明度、移除、重启；原图移动后仍有效 |
| F12 自定义配色 | TokenEditor：模式、色板、对比提示、单项重置 | 浅深独立、合法值预览、非法值不覆盖 |
| F13 外观组合 | AppearancePresetManager：保存/应用/导入/缺依赖 | 应用明确范围；不触发安装代码或后台任务 |
| F14 布局恢复 | LayoutRecovery：错误、上次有效布局、管理插件 | 当前布局失效仍能设置/恢复包/导出草稿 |

原型验证选择、预览与继承关系。真实应用验收另含：双端缩放、屏幕阅读器、IME、CodeMirror 撤销链、进程不重启、背景内存、50 次布局切换和 30 分钟稳定性。对应 [接口](../architecture/INTERFACES.md) 与 [实施计划](../implementation/IMPLEMENTATION_PLAN.md)。
