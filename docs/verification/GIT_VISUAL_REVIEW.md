实现约束：差异工具栏的暂存回调由 GitPanel 提供，保存的回调通过 ref 读取当前文件、快照、忙碌、启用和未保存状态；不在 DiffSurface 另写 Git。冲突通过 Root 的固定 `git-conflict-slot` portal 承载，GitPanel 在开关及卸载时通知 Root。打开差异先关闭冲突。历史 DiffSelection 仅附提交元数据及文件列表。

冲突结果需要真实磁盘预览，因此 `git_conflict_get` 增加 `worktree` 只读字段：最多 128 KiB，明确不存在/二进制/非 UTF-8/截断状态；符号链接显示链接本身，不读取目标。原有选择和暂存接口未改变。

验证：桌面 TypeScript 检查通过；真实 Git 测试 `histories_branches_deleted_files_and_conflict_sources` 通过（增加冲突标记预览与选择 stage3 后磁盘预览断言）。没有构建或操作当前候选版 5，没有把设计截图当成产品截图。此前 18 项 Git 集成与压力报告仍对应其记录的版本/二进制 SHA；本次只重测受影响的冲突路径。
