# Horizon 本机使用指南

Horizon 把多个本地项目放在同一个工作区，提供代码阅读与编辑、Git、插件、终端、项目启动和 Pi 助手。文件始终保留在你选择的目录中。

## 安装与启动

安装包、构建身份和验证边界见 [Windows 试用版说明](WINDOWS_TRIAL.md) 与 [macOS 本机候选包说明](MACOS_CANDIDATE.md)。Windows 安装器为 x64 的 `setup.exe` / `.msi`。

Apple Silicon macOS 的本机构建输出位于：

- `artifacts/macos/Horizon-0.1.0-macOS-arm64.dmg`：打开后将 Horizon 拖入 Applications。
- `artifacts/macos/Horizon-0.1.0-macOS-arm64.zip`：解压后打开 Horizon.app。
- `apps/desktop/src-tauri/target/release/bundle/macos/Horizon.app`：本机构建的应用本体。

macOS 产物未使用 Developer ID 签名与公证；Windows 试用版未签名。具体构建身份、实际通过范围与未验证项目，以[验收记录](verification/README.md)为准。

运行打包应用无需安装 Node.js 或 Rust。Git 功能使用本机 Git，可在“设置 → Git → Git 程序”选择可执行文件，再点“检测 Git”。未安装 Git 时仍可阅读、编辑和搜索本地文件；Git 面板会提示配置路径。Pi 助手另需安装或选择 Pi runtime，见下文。

从源码启动需要 Node.js 20.19+（20.x）或 22.12+ 与 Rust；本次使用 Node.js 24。macOS 另需 Xcode Command Line Tools，Windows 另需 Visual Studio C++ Build Tools：

```sh
npm ci
npm run desktop
```

构建前端：`npm run desktop:build`。生成本机 release：`npm run desktop:release`。macOS 产物为应用、DMG 和 ZIP；Windows 产物为 NSIS / MSI 安装器。

## 项目与文件

点击“添加本地项目”，选择项目根目录。项目导航用于切换；“项目总览”管理工作区、项目顺序和固定状态。点击项目旁的“…”或右键，可固定、改名、在文件管理器中显示、配置启动方案、休眠或移除记录；键盘可用 Shift+F10 打开菜单。菜单中的“项目设置”可移动分组或重新定位失效路径。移除记录不删除源码。

手动休眠当前项目后，工作台显示“项目已休眠”，保留文件标签信息。点击“恢复项目”重新载入阅读位置和按需服务；“休眠偏好”打开项目与资源设置。已手动暂停或禁用的扩展保持原策略。

目录没有读取权限时，恢复权限后点击“重试”；目录移动或磁盘未连接时，可连接磁盘后重试，或用“重新定位目录”选择新位置。重新定位保留原项目关联与会话。

下文快捷键以 macOS 表示；Windows 对应使用 `Ctrl` 替代 `⌘`，保存全部为 `Ctrl+Shift+S`。也可在设置中自定义。

文件树按目录展开。文件操作菜单位于每行右侧；删除使用系统废纸篓。`⌘P` 快速打开，`⌘⇧P` 打开命令，`⌘S` 保存，`⌘F` 查找，`⌘⇧F` 搜索项目磁盘内容。搜索结果不会把未保存缓冲区混入磁盘结果。

文件标签上的未保存标记与 Git 更改是不同状态。保存遇到外部变更时，先比较内容，再决定保留哪一份。大文件、二进制或不支持的编码会显示明确的只读或分段提示，部分加载内容不能覆盖完整原文件。

文件无法读取时，标签会显示具体路径与恢复操作。恢复权限或连接磁盘后点“重新尝试”；文件已移动时，点“重新定位…”选择文件，再核对路径和内容。已有未保存编辑会保留，可另存副本，或在确认新位置后选择“保留当前编辑并关联”；关联后仍需保存。“放弃当前编辑并载入”会改用所选文件的内容。选择文件和确认关联本身不会写入所选文件。

未保存编辑保留独立的恢复副本，不会因此写入项目原文件。停止输入 2 秒后备份；连续输入时每 10 秒触发备份。正常退出前会等待最新草稿写入：没有未保存文档和运行资源时直接退出，否则显示待处理内容，可选择保存、保留恢复草稿或放弃编辑。草稿写入失败时不会继续退出。强制退出或断电后，只能恢复最近一次成功写入的草稿，尚未落盘的编辑可能丢失。

重启后按提示查看和恢复；也可从“设置 → 数据与隐私 → 查看恢复草稿”预览或导出。当前不会自动将恢复稿载入编辑器，恢复后仍需手动保存到原文件。即使编辑器插件停用，宿主仍提供草稿预览与导出。移除项目时可选择保留恢复草稿，之后仍能在这里查看和导出。

## Git

侧栏“Git”区分未暂存与已暂存更改。先打开差异，确认基线，再暂存需要提交的文件。提交按钮只提交已暂存内容；推送是独立操作。

“历史”查看提交，“分支”管理分支与远端同步。拉取使用快进方式。脏工作区、冲突或远端错误会保留当前改动和提交说明，不自动 stash 或强推。

## 插件与外观

右上角插件中心是固定入口。可安装本地 `.horizon-extension` ZIP 包，查看来源、版本、权限、贡献点与依赖，按项目暂停、全局停用、卸载或恢复预装包。安装与启用后，插件仍按需要激活。

“能力预设”提供极简阅读、代码审查、项目开发与自定义。应用前先查看启用、停止、缺包和文档影响；选择开发能力不会自动运行终端或项目命令。

暂停项目 A 的扩展不会停止项目 B；全局停用则作用于全部项目。涉及运行任务、未保存文档或依赖的操作会先列出影响。外部插件示例与打包方法见[扩展开发指南](developer/EXTENSIONS.md)。

“设置 → 外观”集中提供“主题与配色、布局与尺寸、背景图片、外观方案”四个页签。布局按结构命名：经典侧栏、一体侧栏、顶部标签、紧凑工具栏、折叠导航、卡片分区、展开式项目目录、底部导航；主题仍独立选择。全部外观设置全局共用，切换项目保持一致。首次升级会保留当前项目的外观作为全局值，并备份原配置。

界面字号、代码字体与字号、界面密度、减少动效、快捷键、Git 程序路径及默认差异视图也全局共用。缩进、自动保存、文件显示、Git 自动刷新和后台休眠允许项目覆盖；各项标注实际来源。在编辑器、项目与资源、Git 设置中，“设置对象”可选全局默认或当前工作区的具体项目；选择项目会同步切换工作台，设置窗口保持打开。“使用全局设置”取消该项目的单独设置。

macOS 原生菜单“View”提供页面放大、缩小与“实际大小（100%）”，范围为 50%–200%。文字和控件一起缩放；较小的可用区域会切换为紧凑排列，设置与表单内容可滚动。

## 终端与项目启动

启用终端插件后，在底部“终端”中新建会话才启动 shell；Windows 默认 PowerShell。隐藏面板后进程继续运行；结束会话才停止。项目导航上的运行标记提醒后台仍有活动资源。

“设置 → 项目与资源”管理启动方案。发现 `package.json` 脚本只列出候选，不直接执行。方案可包含多个命令、依赖、工作目录、就绪条件和 URL。检查启动计划并授权后执行；可从工具栏停止或重启，日志保留实际失败原因。

## Pi 助手

先在插件中心启用 Pi Agent，再打开“设置 → AI 连接”。展开 Pi runtime 卡片，可安装 Horizon 受管的官方 Pi 1.4.0，或在“使用已有 Pi”输入可执行文件绝对路径并检测版本。受管安装下载固定官方发行并校验摘要，不下载模型，也不要求系统安装 Node.js 或 npm。自行使用 npm 安装 Pi 时，Node.js 和 npm 由你管理；本版仅接入检测通过的 1.4.0。

runtime 卡片会区分“Horizon 受管安装”和“用户安装”。“移除受管 Pi”只清除 Horizon 管理的 runtime，运行中会拒绝移除；连接和历史另行管理。接入已有 Pi 不修改或删除它。需要恢复时重新安装受管版本即可。

添加连接时填写名称、提供商 ID、API 协议、服务地址与模型 ID。认证可选择 Horizon API key、Pi 已有认证，或本地服务/外部认证。Horizon API key 可存系统凭据存储或仅用于当前会话；Pi 已有认证保存在 Pi 的专用认证目录。无认证的 loopback 服务无需填写密钥，Horizon 不启动或关闭该推理服务。保存后显示“已配置 · 未验证”；点击“测试”会由 Pi 发送不含项目内容的固定文本，成功才显示“已验证”。真实服务测试可能产生模型费用。

模型连接可设为全局默认，项目可单独引用；“使用全局设置”移除项目覆盖。每个项目各自保留会话、未发送内容与附件。发送前在“添加上下文”明确选择磁盘文件、未保存编辑内容或 Git 差异；聊天请求关闭工具，只接收所选快照。

若提示附件编辑版本已变化，移除旧附件并重新附加当前内容；Git 差异缓存过期时，重新打开差异后附加。输入会保留，处理后可点“重新发送”。

首版任务模式要求项目具有有效的 Git HEAD；尚无提交的仓库可先使用聊天。任务在隔离工作副本中运行。写文件与命令请求先显示授权卡，点击“查看授权请求”检查文件或完整命令及工作目录，再允许一次或拒绝。关闭授权弹窗不会自动批准。任务修改先进入审查，再按原文件版本应用；应用到已打开编辑器时保留未保存状态，可撤销后再决定是否保存。原文件在任务期间变化时，先处理冲突。

“停止”会等待执行停止与资源回收，不撤回已经完成的文件操作。会话历史可以恢复，恢复本身不重发输入。完成后 Pi 退出，后续输入再按需启动。真实供应商调用需要你自己的连接与凭据；本项目的受控本地协议服务测试不等于真实供应商验证。

## 问题与诊断

“设置 → 数据与隐私”可导出配置和诊断。诊断包含资源计数及编辑器延迟统计，不包含密钥或文档正文。清理数据前会说明受影响类别；删除原项目代码应使用文件管理功能。

实际测试、已知问题、性能样本和截图见[验收入口](verification/README.md)。[设计图集](../design/index.html)是设计参考，不代表真实应用测试结果。
